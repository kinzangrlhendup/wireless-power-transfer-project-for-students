# Contributing

Contributions should improve reproducibility, technical accuracy or teaching value.

1. Create a focused branch.
2. State whether every result is calculated, simulated or measured.
3. Include component values, model versions and test conditions.
4. Do not upload copyrighted vendor models without redistribution permission.
5. Do not upload personal student information.
6. Run `python scripts/validate_repo.py` before submitting changes.

Technical corrections should cite a primary source or show a reproducible
calculation.
