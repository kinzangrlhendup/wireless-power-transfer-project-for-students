# Student result submission

Create a folder named with a non-sensitive student identifier and date, for example:

```text
student-07_2026-09-15/
```

Include:

- `parameters.csv` — all component and sweep values;
- `waveforms.csv` — exported waveform data;
- `schematic.png` — the tested schematic;
- `plots/` — clearly labelled figures; and
- `report.md` — observations, interpretation, limitations and conclusion.

Every result must be labelled as **calculated**, **simulated** or **measured**.
Do not commit names, email addresses, student numbers or other personal information.
